# Устройство приложения

## Модули

`lib/main.dart` инициализирует необязательное подключение к Supabase и запускает `StudentApp`. Основной интерфейс разделён на «Сегодня», «Задания», «Пары» и «Профиль».

| Файл в `lib/student/` | Назначение |
| --- | --- |
| `student_app.dart` | Вход, регистрация, корневая навигация |
| `student_store.dart` | Состояние, операции с данными, демо и Supabase |
| `student_models.dart` | Профиль, предмет, пара, задание, материал и чеклист |
| `student_screens.dart` | Основные экраны, расписание и профиль |
| `student_assignment_screens.dart` | Детали задания и редакторы |
| `student_kanban.dart` | Перетаскивание, место вставки, автопрокрутка и отмена |
| `student_board_order.dart` | Сохраняемые позиции карточек |
| `student_motion.dart` | Переходы и поддержка уменьшения анимаций |
| `student_theme.dart`, `student_widgets.dart` | Палитра и общие компоненты |

## Сохранение

Демо хранится на устройстве под отдельным ключом `tasko.students.v1`. Серверные данные используют таблицы `student_profiles`, `student_subjects`, `student_classes`, `student_assignments` и приватный bucket `student-materials`. Все серверные операции выполняются от имени вошедшего пользователя; RLS ограничивает доступ владельцем.

Записи заданий содержат описание, срок, напоминание, чеклист, материалы и связь с предметом/парой. `boardOrder` хранит строковую позицию в колонке; статус и позиция сохраняются одним обновлением. Старые записи без позиции упорядочиваются по сроку.

Изменения проходят через последовательную очередь `StudentStore`. Неудачная операция восстанавливает прежнее состояние. Редакторы сохраняют черновик при ошибке и не записывают отменённые изменения. Realtime-синхронизация между уже открытыми устройствами не подключена.

## Навигация и обратная связь

Корневые разделы остаются в дереве с сохранённым состоянием. Неактивный раздел не отображается и не получает фокус; входная анимация применяется только к выбранному экрану. Вложенные страницы используют непрозрачный сдвиг. Системное уменьшение анимаций отключает пространственные переходы.

В канбане видны исходное место, место вставки, сохранение и результат переноса. Ошибка возвращает карточку и позволяет повторить действие. Временные сообщения закрываются через 3 секунды, с действием отмены — через 5 секунд; новое сообщение заменяет предыдущее.

## Прежняя версия

Предыдущий планер управления проектами изолирован в `lib/legacy/`, его тесты — в `test/legacy/`. Он не импортируется основной точкой входа. Отдельный запуск:

```sh
flutter run -t lib/legacy/legacy_main.dart
```

Старая SQL-схема сохранена в `supabase/legacy/` как справочный материал и не применяется к студенческой базе.
