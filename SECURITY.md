# Сообщения об уязвимостях

Не публикуйте рабочие пароли, токены, персональные данные или приватные вложения в issues и pull requests. Для чувствительного сообщения используйте приватное обращение к владельцу репозитория; если доступна функция GitHub Report a vulnerability, отправьте сообщение через неё.

Укажите затронутую версию, условия воспроизведения и возможные последствия. Для примеров используйте тестовые данные.
